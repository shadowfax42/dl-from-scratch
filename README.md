# Deep Learning from Scratch – My Personal Implementation

This repository documents my journey through **_Deep Learning from Scratch_ by Seth Weidman (O’Reilly)**. I'm working through the book chapter by chapter and writing **every model, concept, and algorithm from scratch using only Python and NumPy**.

The goal of this project is deep understanding — no high-level libraries, no shortcuts. Just core principles and pure Python.
